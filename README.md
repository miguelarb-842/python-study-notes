# Python Roadmap

> [!CAUTION]
> Esto no es un curso desde cero. Ya tengo conocimientos previos de programación y de Python, así que esto funciona más como un **repaso a fondo** para reforzar fundamentos (memoria, referencias, buenas prácticas) antes de avanzar a temas más complejos. Ahora mismo apenas voy por el tema de **Listas** — el resto del roadmap listado abajo todavía no se ha desarrollado.
