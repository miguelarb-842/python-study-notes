# Cadenas
Las cadenas de texto son un tipo de dato `str` (string). 

Python ofrece muchos métodos integrados para manipularlas: 

buscar coincidencias, validar su contenido, transformar mayúsculas/minúsculas, entre otros.
una cadena la podemos definir con cualquier tipo de dato caracter o numero dentro de un "" o ''

---

```python

```
